# LSE Terminal 0.0.14 — flatmoonsociety fork

This release combines the fork's backtest report, strategy, data download, and local development work on top of upstream 0.0.13.

## Downloads

| Platform | Installer |
| --- | --- |
| Windows 10/11, x64 | `LSE.Terminal.Beta.Setup.0.0.14.exe` |
| macOS, Apple Silicon (M1 and newer) | `LSE.Terminal.Beta.0.0.14.arm64.dmg` |
| macOS, Intel | `LSE.Terminal.Beta.0.0.14.x64.dmg` |

Choose the installer from **Assets** below. Each Mac build also includes a ZIP archive. `SHA256SUMS.txt` lists SHA-256 checksums for the downloadable files. The YAML and blockmap files support application updates.

## Changes

- Detailed backtest reports in editor tabs, including equity, trade analytics, and export/print support.
- Collapsible strategy plot panes.
- ATR normalized phase momentum strategy, instrument-aware futures P&L, and full-history defaults. Strategy integrity halts now produce an explicit error.
- Chunked history downloads with shared request pacing, retry handling, coverage validation, and preservation of an existing dataset when an import fails.
- Isolated local development profiles and a consistent 0.0.14 version across the desktop shell and Python engine.
- Native builds for both Mac architectures and Windows x64. Update checks now follow this fork's GitHub releases.

## Installation and limits

These builds are **unsigned**; the Mac builds are **not notarized**. Windows may show SmartScreen. macOS may require **System Settings → Privacy & Security → Open Anyway** after the first launch attempt. Use that option only after confirming that the download came from this repository. Unsigned macOS builds require manual updates; the presence of update metadata does not make Squirrel.Mac accept an unsigned application.

The builds bundle the Python engine and the frontend. Both Mac architectures are native builds; the Intel download is separate from the Apple Silicon download. Existing installations that still follow the upstream update feed need this fork installer downloaded manually.

The ATR strategy is available for research, but exact NinjaTrader trade and fill parity remains unresolved. Provider data can contain incomplete sessions, which the supplied strategy rules exclude. The default strategy results exclude commission and slippage.

The frontend production bundle builds successfully. The repository-wide TypeScript check still has unresolved auth/API/chart type errors; it is not a passing release check for this version.
