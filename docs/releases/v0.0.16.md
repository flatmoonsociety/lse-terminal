Download Binance Spot and futures history directly into your data library, with available-history dates and resumable downloads.

## Changes

- **Provider selector:** MY DATA → Import market data now offers LSE Data and Binance. Binance uses public market-data endpoints without an API key.
- **Spot and futures:** choose Spot, USD-M Futures or COIN-M Futures, including perpetual and dated contracts present in Binance's catalog. Each market has separate library files and download checkpoints.
- **Available history:** selecting an instrument and timeframe shows its first and latest completed candles, duration, and estimated candle counts for the full history and selected dates. Counts are estimates because exchange gaps can reduce the actual download.
- **Complete downloads:** choose Max or custom UTC dates and save paginated history as one CSV. Downloads respect request limits, retry temporary errors, and resume verified pages after interruption. Supported intervals are 1m, 5m, 15m, 30m, 1h, 4h, 1d and 1w.
- **Futures data quality:** request windows handle Binance's futures pagination limits; expired-contract history stops at delivery rather than including flat candles emitted after settlement. Imports retain contract, settlement and volume information. Unicode ticker names use distinct storage filenames.
- **Import dialog:** clearer history and unit details, a larger desktop layout, responsive controls, and protection against stale search or history responses when switching selections.

## Installation and data scope

The installers bundle the Python engine and frontend. These builds are **unsigned**, and the Mac builds are **not notarized**. Install updates manually on Windows and macOS; the current automatic updater requires signed builds.

Binance access depends on its network and regional availability. The instrument list follows Binance's current catalog; expired contracts removed from that catalog are not automatically discoverable.

Futures support in this release imports historical OHLCV. Backtests do not simulate funding or margin liquidation, and the existing linear P&L engine does not reproduce inverse COIN-M settlement in cryptocurrency. Spot and USD-M volume is in the base asset; COIN-M volume counts contracts.

Live verification covered complete daily BTC history on all three markets, multi-page minute downloads on both futures markets, dated and expired contracts, and Unicode symbols. Browser checks covered the provider-to-library flow at desktop and narrow widths.
