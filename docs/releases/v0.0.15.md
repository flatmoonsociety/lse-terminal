## Changes

- **Portfolio backtesting:** combine saved Python strategies across instruments using fixed capital allocations, reserve cash, combined equity and statistics, and results attributed to each component.
- **Past backtests:** save complete individual and portfolio reports, strategy source snapshots, and research settings; reopen them after restarting. Saving now uses an inline name field with progress, error feedback, retry, and duplicate protection.
- **Commission controls:** choose cash per contract/unit per side or a percentage of traded notional. Configure each portfolio component separately. New UI runs start at 2.50 account-currency units per side; adjust this to your broker's actual fees. API callers retain the zero-fee default when no options are supplied.
- **Auditable P&L:** reports distinguish gross trading P&L, commission, and net P&L. The ledger and CSV expose fees per trade; saved reports retain fee assumptions. Equity and performance statistics include fees once, and first-bar fees now count toward drawdown.
- **Benchmark comparison:** strategy and buy-and-hold portfolios use the same starting cash, with aligned-time chart comparisons and calendar-time annualized returns. Futures benchmarks are cash price proxies, not margined contract holdings.
- **Research diagnostics:** daily block-bootstrap simulations, chronological and annual comparisons, dependence on the best trades, extra-cost stress, and walk-forward parameter testing from individual strategy reports.
- **Strategy work:** ATR session-gap handling and instrument-aware contract economics; the Raschke strategy port is included in the repository and as a separate release asset, with the updated 0.45 trend-ratio default.

## Installation and research limits

The installers bundle the Python engine and frontend. These builds are **unsigned**, and the Mac builds are **not notarized**. Unsigned macOS applications require manual updates. Download installers only from the intended repository and check the supplied hashes.

Older saved reports remain unchanged and may lack recorded commission details; rerun to apply new fee settings and record the breakdown. Portfolio allocations do not enforce futures margin or leverage limits. Shared margin, automatic rebalancing, and FX conversion are not simulated. Match component P&L currencies to the portfolio currency.

Research simulations are diagnostics, not evidence that a strategy will remain profitable. Exact NinjaTrader trade/fill parity remains unresolved; different feeds, sessions, gaps, and execution assumptions can change results.

The frontend production build, focused backtest TypeScript checks, frontend regression suites, and desktop tests pass. The repository-wide TypeScript check retains known auth/API/chart errors outside the backtesting changes.
