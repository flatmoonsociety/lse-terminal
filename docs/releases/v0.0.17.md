# LSE Terminal 0.0.17 — flatmoonsociety fork

Faster backtest accounting and substantially quicker reports for long histories, including saved individual and portfolio backtests.

## Changes

- **Faster backtest engine:** calculate per-trade equity over NumPy array slices and reuse compiled strategy code across repeated runs. Trade fills, commissions, and accounting retain their existing behavior.
- **Quicker report delivery:** avoid redundant conversion of new individual and portfolio results, and serve saved report JSON directly from storage after decompression.
- **Responsive large-history charts:** calculate report statistics in fewer passes and limit the plotted overview to a representative sample that retains extrema and missing-data gaps. Zooming restores the original observations in the selected range. Statistics and JSON/CSV exports continue to use the complete results.
- **Faster report navigation:** build trade-analysis charts when opened and filter or sort ledger row indices without copying every trade.

## Measured performance

Local comparisons against 0.0.16 on the same machine:

| Workload | Before | After |
| --- | --- | --- |
| Accounting over 300,000 bars and 2,990 trades | 1.27 s | 0.10–0.13 s |
| Browser report rendering over 1 million bars | 3.76 s | 0.37 s |
| Server preparation of a saved 3.59-million-bar NQ report | 33.14 s | 0.49 s |

These timings measure the stated stages, not total strategy execution. The saved NQ report opened in approximately 3.9 seconds in the local browser check; actual timings depend on hardware, strategy, and report size. Repeatable accounting, transport, and chart benchmarks are included in the repository.

## Installation and verification

The installers bundle the Python engine and frontend. Signing availability is recorded by the release build; use manual installation for unsigned builds.

Verification of the performance changes passed 285 Python tests with one optional test skipped, the frontend production build, report regression checks, and browser checks for saved reports, filtering, sorting, zoom, and all report tabs. The repository-wide TypeScript check retains the same 51 errors as 0.0.16, outside these changes.
